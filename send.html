Good to know

Where does the file go?

Directly from your browser to theirs. A tiny server only passes the initial "handshake" so the two browsers can connect; after that the file streams peer-to-peer and we never see it. Nothing is saved and there is no link anyone could find later.

Do we both need to be online?

Yes. This is a live transfer — like a phone call for files. Keep both tabs open until the progress bar reaches 100%. There's no mailbox holding the file for later.

How big a file can I send?

Up to 2 GB. The receiver's browser reassembles the file in memory, so very large transfers work best on a computer rather than a phone.

Is it secure?

WebRTC data channels are encrypted (DTLS) end to end. The pairing code is one-time and random. Still, only share the code with the person you mean to — whoever enters it first receives the file.

It won't connect — why?

A small number of very restrictive networks (some corporate or mobile carriers) block direct connections. Try a different network, or both switch to Wi-Fi.
