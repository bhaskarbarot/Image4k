# Image4k.org

**Bhaskar Solution** — 45+ free tools: image tools (**Make HD / 4K**, **Resize**, **Compress**, **Remove Background**,
OCR, watermark remover, **QR code generator**), PDF tools, **developer tools**, **API & backend tools** and a
**data transformation workbench**.

🌐 **Live site: [https://image4k.pages.dev](https://image4k.pages.dev/)**

Static site, no framework, no build step. Images, PDFs and developer data never leave the visitor's device.
The only server-side parts are two small Cloudflare Pages Functions — the API **secure proxy** and the
**webhook tester** (see `docs/DEPLOYMENT.md`).

## Features
- Drag & drop, file picker or paste · up to **10 images** per batch · 80 MB each
- Input: JPG, PNG, WebP, AVIF, GIF (first frame), BMP, SVG, HEIC/HEIF (iPhone)
- Output: JPG, PNG, WebP, BMP, TIFF, ICO (+ AVIF where the browser can encode it)
- **Make HD**: 2×, 4×, 4K (3840 px), 8K (7680 px) — **AI super-resolution** in the browser:
  "AI Best" = RealESRNet_x4plus (fidelity-trained, keeps text/shapes correct — scored best of 14 models in our text + photo benchmark),
  "AI Fast" = realesr-animevideov3 (~10× quicker); WebGPU when available, otherwise multi-threaded WASM;
  "Classic" (Lanczos3 + unsharp mask) as instant fallback. The Resize tool uses the same AI when it enlarges.
- **Resize**: 90+ presets (Instagram, YouTube, Facebook, X, LinkedIn, Pinterest, Twitch, ads, print, ratios, HD/4K/8K),
  custom size with aspect lock, percent, crop / fit (blur, color, transparent border) / stretch, "4K Ultra HD" toggle,
  print presets tagged 300 DPI
- **Compress**: quality slider or exact target size (KB); PNG compressed by color quantization; keeps the original if it is already smaller
- **Remove BG**: AI cut-out (ormbg for any object, MODNet for people), transparent / any color (palette + picker + hex) / blur,
  soft-natural-sharp edges, crop to subject
- Before/after compare with 100% zoom, per-image download, "Download all" ZIP
- Settings remembered per tool, mobile friendly, accessible (keyboard, ARIA), SEO + Open Graph + JSON-LD

## PDF Tools (`/pdf`) — in progress
Matte wine-red & white PDF editor, 100% in the browser (nothing uploaded), one PDF at a time.
- **Engine:** PDFium (Chrome's PDF engine) as WebAssembly — `assets/vendor/pdfium-2.15.1/` (@embedpdf/pdfium, MIT; PDFium Apache-2.0/BSD).
- **Phase 1 (done):** click any text to edit it **in its original font**, drag text/images to move, delete, add text,
  add/replace/resize images, signatures (draw / type / upload), undo/redo, password-protected PDFs, download.
  If new letters are missing from the PDF's embedded (subset) font, that line switches to the closest matching
  Liberation font (`assets/vendor/liberation-2.1.5/`, SIL OFL 1.1) — same size, colour and position.
- **Next phases:** merge · split · organize (rotate/reorder/crop/delete) · PDF↔images · extract text/images/tables ·
  compress · AI enhance to HD.
- Limits: text is edited line by line (no paragraph reflow); scanned PDFs need OCR (planned); complex scripts
  (e.g. Hindi/Gujarati) may not shape correctly when edited.

## Deploy
**Live:** [https://image4k.pages.dev](https://image4k.pages.dev/) — Cloudflare Pages, auto-deploys on every push to `main`.

Cloudflare Pages build settings:

| Setting | Value |
|---|---|
| Framework preset | None |
| Build command | `mkdir -p dist && tar -c --exclude-from=.assetsignore --exclude=./dist . \| tar -x -C dist` |
| Build output directory | `dist` |

`.assetsignore` keeps repo-only files (README, serve.py, configs) off the website — add any new private file there.
`_headers` (security + caching) and `404.html` are applied automatically; `/privacy.html` is served as `/privacy`.

Other hosts:

- **Netlify**: same build command and output directory; `_headers` is applied automatically.
- **Cloudflare Workers**: `wrangler.jsonc` is included (serves `404.html`, uses `.assetsignore`).
- **Vercel / nginx / Apache**: copy the headers from `_headers`. nginx example:
```nginx
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-eval' 'wasm-unsafe-eval' blob: https://cdn.jsdelivr.net; worker-src 'self' blob: data: https://cdn.jsdelivr.net; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src https://fonts.gstatic.com; img-src 'self' blob: data:; connect-src 'self' blob: data: https://cdn.jsdelivr.net https://huggingface.co https://*.huggingface.co https://*.hf.co; media-src 'self' blob:; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'; upgrade-insecure-requests" always;
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "credentialless" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "no-referrer" always;
error_page 404 /404.html;
```
COOP/COEP enable multi-threaded WebAssembly, which makes background removal ~3–4× faster in Chrome/Edge/Firefox.

## Notes
- **After changing CSS or JS**, bump the `?v=` version on `style.css` / `*.js` links in the HTML pages so every browser loads the new file immediately.
- AI upscaling: onnxruntime-web 1.31.1 loads from cdn.jsdelivr.net; the models are served from `/assets/models/`.
  Speed (measured, 6-core CPU, no GPU): AI Fast ≈ 1 min per input megapixel, AI Best ≈ 10 min per input megapixel;
  with WebGPU both take seconds. Flat background tiles skip the network, so screenshots/documents are much faster.
  CPU-only visitors get a time estimate and can switch to AI Fast before a long AI Best run.
  RealESRNet is stored with fp16 weights (33.8 MB, split in two <25 MB parts for any static host) and computed in fp32
  (max deviation vs PyTorch 0.0007). Models are cached in the browser (Cache Storage) after the first download.
- The background-removal engine (Transformers.js 4.3.2) loads from cdn.jsdelivr.net and the models from huggingface.co
  the first time the tool is used, then the browser caches them. To self-host, change `TJS_URL` and `MODELS` in `app.js`
  and set `env.remoteHost` to your own model mirror.
- `'unsafe-eval'` in the CSP is required by the HEIC decoder (heic2any).
- Max output is capped to ~40 MP on desktop and ~16 MP on phones / low-memory devices to avoid browser crashes; the UI says when this happens.
- Licenses: pica, JSZip, heic2any — MIT; Transformers.js, ormbg, MODNet — Apache-2.0. All allow commercial use.
